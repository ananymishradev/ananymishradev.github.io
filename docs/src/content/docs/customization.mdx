This site uses the **Starlight Rapide** theme — a dark/light dual-theme built for the [Starlight](https://starlight.astro.build) documentation framework.

## Colour Palette

The theme exposes CSS custom properties for every major colour group. You can override any of them in your own stylesheet.

The base hue is warm (`--sl-hue-base: 17`), with accent greens, oranges, blues, purples, and reds for semantic elements like asides, badges, and code markers.

## Custom CSS

Additional CSS is loaded from `src/styles/custom.css`. This is where the site font — **Cormorant Garamond** — is defined and applied.

```css
/* src/styles/custom.css */
@layer my-reset, starlight, rapide, my-overrides;
```

Use your own `@layer` rules to control the cascade and override any theme defaults.

## Components

The site overrides Starlight's default `SiteTitle` component to render navigation links instead of a plain site title. Check `src/components/SiteTitle.astro` to adjust the header links.
