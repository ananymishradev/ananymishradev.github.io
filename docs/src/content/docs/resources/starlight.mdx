A collection of tools, libraries, and references I reach for regularly.

## GPU Programming

- [CUDA Toolkit Documentation](https://docs.nvidia.com/cuda/) — Official reference for CUDA C++ and PTX.
- [OpenAI Triton](https://triton-lang.org/) — A Python-based language for GPU programming.
- [PyTorch C++ Extensions](https://pytorch.org/tutorials/advanced/cpp_extension.html) — Write custom ops with CUDA and C++.

## Low-Latency Systems

- [Linux man pages: `futex`](https://man7.org/linux/man-pages/man2/futex.2.html) — Fast userspace mutex primitive.
- [Intel Intrinsics Guide](https://www.intel.com/content/www/us/en/docs/intrinsics-guide/) — x86 SIMD instruction reference.

## Performance Analysis

- [NVIDIA Nsight Compute](https://developer.nvidia.com/nsight-compute) — GPU kernel profiling.
- [perf / Linux profiling](https://perf.wiki.kernel.org/) — CPU performance counters.
- [FlameGraph](https://github.com/brendangregg/FlameGraph) — Stack trace visualisation.
