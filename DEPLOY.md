# Deploying this site

Everything is static: `pnpm build` writes plain files to `dist/`, and GitHub
Actions publishes that folder to GitHub Pages. There is no server to restart and
no database to migrate.

- Live URL: <https://ananymishradev.github.io/>
- Repo: <https://github.com/ananymishradev/ananymishradev.github.io>
- Workflow: `.github/workflows/deploy.yml`

## Once

```sh
git clone https://github.com/ananymishradev/ananymishradev.github.io.git
cd ananymishradev.github.io
pnpm install
```

Requirements: Node 22.12 or newer, pnpm 12, git. `gh` is optional but handy.

In the repo on GitHub, **Settings → Pages → Build and deployment** must have
**Source: GitHub Actions**. That is the only setting the deploy depends on.

## Every change

```sh
git pull                      # start from what is deployed
pnpm dev                      # edit at http://localhost:4321
pnpm build                    # must pass before you commit
git add -A
git commit -m "content: describe the change"
git push
```

The push to `main` triggers the workflow:

1. checkout
2. `pnpm install --frozen-lockfile`
3. `pnpm build` — `astro check`, `astro build`, Pagefind index, then
   `scripts/prune.mjs`
4. upload `dist/` and deploy it

Watch it with `gh run watch` or in the **Actions** tab. Green means live in about
a minute; Pages sometimes serves the previous build for a few seconds after.

Commit messages follow Conventional Commits, plain and specific:
`content: rewrite about page`, `fix: favicon path`, `ci: bump actions`,
`chore: update astro-sage`.

## `.gitignore` — what never gets committed

| Ignored | Why |
| --- | --- |
| `dist/` | Build output, regenerated on every build and by CI |
| `.astro/` | Generated types from `astro sync` |
| `node_modules/` | Recreated by `pnpm install`; CI installs its own |
| `public/pagefind` | Search index generated at build time |
| `.env`, `.env.production` | Secrets belong in repo settings, not in git |
| `.DS_Store`, `.idea/`, logs | Editor and OS noise |
| `.pnpm-store` | Local package cache |

Committed **on purpose**, do not add these to `.gitignore`:

| Committed | Why |
| --- | --- |
| `pnpm-lock.yaml` | `--frozen-lockfile` in CI fails without it |
| `patches/astro-sage@0.1.5.patch` + `pnpm-workspace.yaml` | The nav order and site-title font live here |
| `.sage-cache/diagrams/` | Pre-rendered SVG diagrams, so CI needs no Chromium |
| `src/content/` | The actual writing |

If `git status` shows `dist/`, `node_modules/` or `public/pagefind`, the
`.gitignore` was edited or bypassed — unstage those paths before committing.

## Adding content

A post is one file in `src/content/posts/`:

```md
---
title: "A title"
description: "One line for lists, RSS and previews."
pubDatetime: 2026-11-15T09:00:00Z
tags: ["cuda"]
draft: false
---

Body text.
```

Pages (about, contact) live in `src/content/pages/`. Site name, author, socials
and feature flags live in `sage.config.ts`. Routes, RSS, sitemap and search are
generated by the theme; do not hand-write them.

## Changing the theme

Never edit `node_modules/`. The two local tweaks (Contact in the nav, nav order,
serif site title) are recorded as a pnpm patch. To change them:

```sh
pnpm patch astro-sage@0.1.5          # opens a temp copy
# edit src/components/Header.astro there
pnpm patch-commit 'node_modules/.pnpm_patches/astro-sage@0.1.5'
pnpm build && git add -A && git commit -m "fix: nav tweak"
```

When upgrading the theme, `pnpm update astro-sage` will warn if the patch no
longer applies. Re-open the patch against the new version, re-apply the changes,
commit the new patch file.

## Replacing the favicon

The icons are generated from `pfp.jpg` at the repo root:

```sh
magick pfp.jpg -define icon:auto-resize=48,32,16 public/favicon.ico
magick pfp.jpg -resize 180x180 public/apple-touch-icon.png
```

## When the deploy fails

| Symptom | Likely cause |
| --- | --- |
| `ERR_PNPM_OUTDATED_LOCKFILE` | `package.json` changed without committing `pnpm-lock.yaml` — run `pnpm install`, commit both |
| `astro check` errors | Type or frontmatter errors; run `pnpm build` locally and fix |
| Build passes, site 404s | Pages source is not **GitHub Actions**, or the `github-pages` environment needs approval |
| `/archives/` or `/series/` 404 | Expected — `scripts/prune.mjs` deletes those routes |
| Diagram SVG missing | Run a local build with Playwright Chromium and commit the new `.sage-cache/diagrams/` entry |

Rolling back is a normal revert: `git revert <sha> && git push`, or re-run an
older successful workflow from the Actions tab.
